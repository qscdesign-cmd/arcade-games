# Arcade Hub 3D

A browser arcade with 50 named playable challenges across five original arcade engines: Snow Rider, Cube Dash, Highway Racer, Space Flight, and Neon Dodge. Each family has 10 progressively faster variants. The perspective racers use lightweight canvas pseudo-3D (not photorealistic 3D). No external dependencies.

## Publish on GitHub Pages

1. Upload `index.html` and `README.md` to the repository root on the `main` branch.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. After deployment, open `https://qscdesign-cmd.github.io/arcade-games/`.

Controls: left/right arrows or A/D, Space/up to jump, P pause, R restart. Touch controls are included.
